# Ghibli Photo Album System

## Overview

The Ghibli Photo Album System is a Django-based web application inspired by the magical and cinematic aesthetic of Studio Ghibli. The system allows users to upload, manage, and organize beautiful photo albums in a peaceful and artistic digital scrapbook environment.

The application features modern responsive design, glassmorphism effects, smooth animations, and CRUD functionality for managing albums and images.

---

## Features

- Upload Ghibli-inspired photos
- Create magical photo albums
- Edit album information
- Delete albums
- Responsive modern UI
- Glassmorphism aesthetic design
- Django CRUD functionality
- Cloud deployment using Render

## Installation

### Clone Repository

```bash
git clone https://github.com/clenymalate07/photo_album_system.git
```

### Navigate to Project

```bash
cd photo_album_system
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run Server

```bash
python manage.py runserver
```
